## 👋 About me

I build AI agents that take over tedious enterprise workflows, the cloud pipelines that feed them, and the full-stack apps people actually click on, mostly in **C#, .NET, Python and Azure**. I like problems that start messy: a folder of PDFs nobody wants to read, a portal someone logs into every morning, a spreadsheet that has to end up in a database by noon.

I care about clean, modular code, APIs that are pleasant to use, and software that quietly keeps working.

## 🛠️ What I built at Midtown Associates

A document's journey through the pipeline I worked on:

**Excel · PDF · JSON arrive** → **AI agents** (Python, C#, Selenium, LLM integration) read them and operate portals → **extract, map and validate** into clean records → **Azure Queue Storage** smooths out the Monday spike → **Azure Blob Storage** keeps every raw and processed file → **features and REST APIs** in the Enercross and NatGasHub products (C#, .NET, SQL) → **Jenkins** build and deploy monitoring.
